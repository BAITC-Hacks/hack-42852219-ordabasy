# Аким на 5 часов

AI-симулятор управления Астаной. Пользователь получает единый стартовый
город, 100 условных единиц бюджета и должен принять ровно пять решений для
пяти синтетических районов.

## Проблема и решение

Городское развитие требует балансировать ограниченный бюджет, отложенный
эффект инфраструктуры и конкурирующие приоритеты. Интерактивная карта
помогает выбрать район, понять его проблемы, собрать пять решений, запустить
двухлетнюю симуляцию и изучить последствия.

```text
Район → проблема → инициатива → 5 решений → симуляция → результат → AI-анализ
```

## Ключевой принцип

**LLM не рассчитывает Astana Quality of Life Score.**

Все числовые результаты производит детерминированный движок симуляции. LLM
получает готовый расчёт и только объясняет сильные стороны, риски,
компромиссы и возможные улучшения.

```text
User
  ↓
Next.js Frontend
  ↓
FastAPI
  ↓
Deterministic Simulation Engine
  ↓
Calculated Result
  ↓
LLM Analysis
  ↓
Explanation
```

Это делает сценарии воспроизводимыми, сравнимыми и тестируемыми.

## Возможности

- SVG-карта пяти районов с QoL-семантикой и клавиатурным управлением;
- проблемно-ориентированная панель района;
- 14 инициатив со стоимостью, лагом и явными trade-offs;
- бюджет 100 ед., ровно пять решений, максимум две меры категории;
- объяснимые блокировки дубликатов, конфликтов и превышения бюджета;
- временная шкала Q1–Q8 без выдуманных промежуточных чисел;
- Score, карта и показатели Before/After;
- раздельные состояния расчёта и AI-интерпретации;
- mock/live API-режимы и обработка ошибок;
- unit- и interaction-тесты.

## Технологии

Next.js 16 App Router, React 19, TypeScript 5, Tailwind CSS 4, Vitest,
React Testing Library, REST API и Python/FastAPI на backend.

## Архитектура

Используется прагматичный Feature-Sliced Design:

```text
src/
├── app/       # маршруты, layout, глобальные стили
├── views/     # композиция экрана и сессионное UI-состояние
├── widgets/   # карта, панели, прогресс, результаты
├── features/  # валидация сценария и запуск симуляции
├── entities/  # district, initiative, decision, simulation
└── shared/    # API-клиент и общая конфигурация
```

Зависимости направлены сверху вниз. Компоненты не вызывают `fetch` напрямую.
Frontend рассчитывает только presentation state: остаток бюджета, количество
решений, категории и доступность UI. Формулы эффектов, синергий, district/city
score и штрафов остаются на backend.

## Данные и Score

Данные синтетические: пять районов, десять показателей и четырнадцать
инициатив. Все показатели имеют шкалу 0–100, где больше — лучше. Базовый
Score: **52.56**.

```text
Score = 0.7 × weightedCityAverage
      + 0.3 × weakestDistrict
      - 1.0 × criticalIndicatorCount
```

Критическим считается значение строго ниже 40. Цвет карты — только
presentation-семантика и не заменяет это правило.

## Установка и запуск

Требуется Node.js 20.9+.

```bash
npm install
copy .env.example .env.local
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Переменные окружения

```env
NEXT_PUBLIC_API_MODE=mock
NEXT_PUBLIC_API_URL=http://localhost:8000
```

- `mock` использует встроенный фиксированный demo fixture;
- `live` отправляет запросы в FastAPI;
- LLM-ключи хранятся только на backend и никогда не имеют префикс
  `NEXT_PUBLIC_`.

## API

Изолированный frontend-адаптер ожидает:

- `POST /api/simulate` — `{ decisions: [{ measureId, districtId }] }`;
- `POST /api/analyze` — рассчитанный результат и исходный сценарий.

Пути и raw response меняются в `src/shared/config` и
`features/run-simulation`, не затрагивая UI. Backend повторно валидирует
сценарий. Ответ `valid: false` не отображается как Score 0.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Тесты покрывают QoL-границы, бюджет, дубликаты, category limit, scope,
несовместимости, выбор района, добавление/удаление решения, блокировку до
5/5, успешный результат и отказ AI после успешной симуляции.

## Официальный пример

| Мера | Район |
| --- | --- |
| M7 — школа + детсад | Нура |
| M8 — поликлиника | Нура |
| M10 — Safe City | Нура |
| M12 — платформа обращений | Весь город |
| M5 — чистое топливо | Сарыарка |

Стоимость: **95 ед.** Ожидаемый Score по спецификации/backend-проверке:
примерно **56.5**. Активируется синергия M10 + M12.

## Ограничения

- В репозитории нет OpenAPI-схемы или backend-кода; live adapter нужно сверить
  с контрактом команды.
- Mock mode — фиксированный demo response, а не второй движок.
- Карта стилизованная и не является точной GIS-моделью.
- Приоритет — desktop/projector; mobile имеет базовую деградацию.

## Дальнейшее развитие

Реальные открытые данные, более точная GIS-визуализация, сравнение сценариев,
детерминированные кризисные события и leaderboard.
